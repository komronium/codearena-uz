Date: 2026-09-27
Follows: 2026-09-27-ui-ux-design.md (sub-project D). The owner asked for another design,
UI and UX review with a free hand ("redesign fully or partly"). Every decision below is
Claude's, made from a screenshot audit of the running app; overrule any of them.

## Decisions

1. **Identity: Samarkand tilework.** Warm ivory paper, *firuza* (turquoise) for actions and
   focus, lapis for information, ochre for streaks and medals; a deep blue-green night
   for dark mode. The mark is an eight-point *khatam* star holding a code chevron (also
   the favicon). A girih lattice (`.ca-girih`, a CSS mask, so any colour) sits faintly
   behind the landing hero, the daily-problem cards, the honest-results tile, the CTA
   band and the profile banner (in the user's tier colour). Surfaces are flatter:
   hairline borders, almost no shadow.
2. **Header**: brand, a search with a `/` shortcut, and an account menu (profile,
   submissions, edit profile, a three-way theme switch, sign out). Guests keep the
   theme button and sign-in/up.
3. **Sidebar**: grouped — Mashq, Musobaqa, Sinf, Admin — with a quiet active state
   (tint + firuza + a tick); the profile moved to the account menu.
4. **Landing**: a short headline ("Dasturlashni musobaqada o‘rganing"), stats inline
   under the buttons, "Qanday ishlaydi" in three steps, and a bento of what is different.
   The contest tile shows the **real** top three of the latest rated contest (from the
   standings, not stored fields); the languages tile lists the active languages.
5. **Home**: a "today" card — daily problem and this week's seven days, solved days in
   gold — beside a stats card; the main column (homework, contests, recent submissions)
   and a side column (duels, next problems).
6. **Problems**: the daily card and picks in one band; difficulty chips with counts (each
   number is what a click shows) and a Hammasi / Yechilmagan / Yechilgan switch; tags as
   quiet `#links` under the title; "Baho" only when some problem on the page is rated;
   the user's progress (solved / open) in the header.
7. **Problem page**: icon-only actions on phones; "Yuborish" uses the primary colour
   (green stays for verdicts and approvals).
8. **Profile**: the contest tiles' month abbreviations (Iyn, Iyl); a note under the
   solved chart when solved problems are hidden by an upcoming contest; the heatmap and
   the rating chart open on the latest weeks on a phone and are keyboard-scrollable.
