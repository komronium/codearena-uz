# Notes given on 2026-10-21 (kept here so they are not lost)

## New Uzbek Latin spelling (law signed by the President; announced on the Telegram channel of the First Lady's office)
Four letters change: O‘ -> Ö, G‘ -> Ğ, Sh -> Ş, Ch -> Ç ("O‘zbekiston" is now written "Özbekiston").
How the site follows it: the source strings stay in the old spelling; `locale_uz/` carries every UI string converted by
`tools/uz_alphabet.py` (built by `tools/i18n_build.py`), listed in `LOCALE_PATHS`. Take `locale_uz` out of
`LOCALE_PATHS` in `config/settings/base.py` to go back. Not converted yet: texts stored in the database (problem
statements, course lessons, contest names, user-typed text), city/school names (apps/accounts/places.py), the duel
question bank. Lato's latin-ext files cover Ğ and Ş.

## Content translation (a side note the owner confirmed: "every problem needs an English version too")
English UI strings are not enough: problem statements, hints, editorials, courses and contests live in the database.
The author writes ONE language (`source_lang`); the other language is added by an admin or the AI and stays closed to
readers until an admin confirms it. Admin pages: `/moderation/translations/`. Command:
`python manage.py translate_content [problems|courses|contests|all] [--workers 4]` (AI drafts, needs ANTHROPIC_API_KEY).
